# Рабочие прогоны

Сюда вынесены временные и проверочные файлы из корня проекта, чтобы корень оставался
читаемым.

- `чертежи/` - DWG-файлы рабочих прогонов и ручных проверок.
- `бэкапы/` - AutoCAD `.bak`, `.dwl`, `.dwl2`.
- `_служебные_архивы/` - отработавшие диагностики, временные папки прогонов и логи.

В корне держим только `README.md` и разовые загрузчики для прогонов. 31.07 корень
разобран по этой схеме: 46 DWG ушли в `чертежи/`, 25 `.bak` в `бэкапы/`, 5 логов и
папки `_package_diagnostics_2026-07-23`, `_package_diagnostics_2026-07-31`,
`_tz_p7_media` - в `_служебные_архивы/2026-07-31/`.

Эталонные DWG остаются отдельно в `../эталоны/`, исходники заказчика - в `../исходник/`.

`ЗАГРУЗИТЬ_GEO_ТЕСТ.lsp` - разовый загрузчик сборки `OPOR_GEO_2026-07-31` с жёстко
прописанным путём. Нужен там, где рядом лежит вторая распакованная копия плагина:
автопоиск в `00_ЗАГРУЗИТЬ_OPOR.lsp` в такой ситуации может поднять чужую папку.

Текущая приёмка авто-TIN (все файлы в `чертежи/`):

- `ETS15_tin_lisp.dwg` — чистая копия для `ETS15` → `OPORTIN` → Var.
- `ETS15_manual_lisp.dwg` — чистая копия для `ETS15` → `ETS15MANUAL` → Var.

Приёмка надёжности авто-TIN (`чертежи/`):

- `ETS16_complex_lisp.dwg` — вогнутый контур, проём, повторный TIN и Var.
- `ETS16_complex_retry_lisp.dwg` — чистый повтор после constrained edge recovery.
- `ETS16_missing_lisp.dwg` — отказ при пропущенной отметке вершины контура.
- `ETS16_conflict_lisp.dwg` — отказ при разных отметках в одной точке.

Приёмка геоотметок (`чертежи/`):

- `Крыша_Власьево_geo_levels_test.dwg` — копия клиентского DWG со слоем `GEO_POINTS`
  для `OPORGEOLEVELS` / кнопки `Гео`, режим `Сетка`, шаг 1 м, ожидается ~204 отметки.
