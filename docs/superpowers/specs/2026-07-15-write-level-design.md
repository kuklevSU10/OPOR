# Инструмент `h` / `write_levl` — дизайн порта (v3.12)

Дата: 2026-07-15. Источник истины:
`12/vba_sources/vba_sources/k_write_levl.bas.txt` и реальная форма
`ufrm_mode` из `oporav2.6.dvb`.

## Семантика VBA

1. Выбрать опорную отметку `otmetka_oporvb` (в интерфейсе — отметка воронки).
2. Выбрать динамический блок `slope`.
3. Последовательно выбирать остальные `otmetka_oporvb`; завершение — Enter/Esc.
4. Ось расчёта равна динамическому свойству `Угол` + 90° + Rotation блока.
5. Расстояние — модуль проекции вектора от опорной отметки к текущей на эту
   ось. Знак стороны VBA теряет, поэтому прибавка всегда положительная.
6. `delta = VBA.Round(percent * distance / 100, 0)` — банковское округление.
7. Новая отметка = опорная отметка + delta. Если исходный текст содержал `+`,
   префикс сохраняется.

Прямая проекция математически эквивалентна, но не бит-в-бит: на ETS9 она дала
`+138/+113`, тогда как VBA через XLine дал `+137/+112`. Поэтому порт повторяет
XLine → Rotate → IntersectWith → двойной Sqr; обе временные XLine гарантированно
удаляются. Дополнительно перед Round вычитается локальный `1e-9`: один и тот же
COM-путь из AutoLISP дал `12.50000000000003/37.50000000000003`, тогда как
фактический VBA ETS9 округлил вниз. Компенсация больше только COM-шума и не
влияет на обычные миллиметровые значения.

## Интеграция

- кнопка `h` в DCL → `write-level`;
- прямая команда `OPORWRITELEVEL`;
- командный fallback `WriteLevel`;
- `?` остаётся `check_height`.

## Приёмка ETS9

При угле 0°, Rotation 0, уклоне 2.5% и опорной отметке `+100` ожидаются:

- y=1000 → `+125`;
- y=1500 → `+137` (фактический VBA ETS9);
- y=500 → `+112` (фактический VBA ETS9);
- y=-1000 → `+125` (модуль проекции).

LISP и VBA сверяются командой `WRITELEVELDUMP` бит-в-бит.
