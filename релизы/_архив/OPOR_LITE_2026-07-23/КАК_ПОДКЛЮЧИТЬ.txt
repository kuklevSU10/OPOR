OPOR — лёгкое подключение через «Группу автозагрузки» (Startup Suite)

Без установщика, без прав администратора, ничего не копируется в системные
папки. Плагин просто лежит в этой папке и загружается сам при каждом запуске
AutoCAD.

ПОДКЛЮЧЕНИЕ (один раз на каждом ПК)
  1. Распакуйте эту папку куда угодно (например, в Документы).
     Важно: папку OPOR держите целиком, файлы внутри не разносите.
  2. В AutoCAD выполните команду:  APPLOAD
  3. В открывшемся окне справа снизу — блок «Группа автозагрузки».
     Нажмите значок портфеля (кнопка «Содержимое...»).
  4. «Добавить...» → выберите файл
          OPOR\opor-loader.lsp
     из этой папки → «Закрыть».
  5. ВАЖНО — в первый раз сделайте обязательно:
     в верхнем списке окна APPLOAD выделите opor-loader.lsp и нажмите «Загрузить».
     • AutoCAD один раз покажет предупреждение безопасности про этот файл —
       нажмите «Загрузить» (Load). Сразу после этого загрузчик пропишет свою
       папку в доверенные расположения НАВСЕГДА.
     • Поэтому больше предупреждений не будет — ни в этом сеансе, ни при
       следующих запусках AutoCAD: команды OPOR/XX грузятся сами и молча.
     Не пропускайте этот шаг: именно он один раз «прописывает» доверие к папке.

С этого момента при каждом старте AutoCAD команды OPOR/XX грузятся автоматически.

ПОЛЬЗОВАНИЕ
  OPOR   (или старый алиас  XX)  — главное меню.
  Прочие: OPORCHECK, OPORCLEAN, OPORTABLES, OPORLOGS, OPORTIN и т.д.

ОБНОВЛЕНИЕ
  Просто замените файлы в папке OPOR новыми — запись в «Группе автозагрузки»
  та же, ничего перенастраивать не нужно.

ОТКЛЮЧЕНИЕ
  APPLOAD → «Группа автозагрузки» → «Содержимое...» → выделить opor-loader.lsp
  → «Удалить».

ПРО ПРЕДУПРЕЖДЕНИЕ БЕЗОПАСНОСТИ (SECURELOAD) — ЭТО НОРМАЛЬНО
  При самой первой загрузке (шаг 5) AutoCAD один раз спросит про безопасную
  загрузку opor-loader.lsp — нажмите «Загрузить» (Load). После этого загрузчик
  сам добавляет свою папку в доверенные расположения, и больше вопросов не будет.
  Проверено на AutoCAD 2023: после этого все модули грузятся без единого запроса.

  Если политика ПК запрещает менять доверенные расположения из программы
  (редко, на корпоративных машинах), добавьте папку один раз вручную:
  Настройка (OPTIONS) → вкладка «Файлы» → «Доверенные расположения» →
  «Добавить» → выберите папку OPOR из этой поставки → OK.
  После этого перезапуск AutoCAD загрузит всё сам.

ПРИМЕЧАНИЕ
  Это облегчённый способ. Есть и полностью автоматический установщик
  (OPOR_v3.31.3) — он сам кладёт плагин в системную папку автозагрузки Autodesk.
  Оба способа равнозначны по итогу; выбирайте, что удобнее.
