OPOR 3.32-geo-levels — установка

1. Полностью распакуйте ZIP-архив в любую папку.
2. Закройте AutoCAD, Civil 3D, Map 3D и Plant 3D, если они открыты.
   Revit закрывать не требуется.
3. Запустите файл 1_УСТАНОВИТЬ_OPOR.cmd:
   - обычный двойной клик — установка для текущего пользователя Windows,
     права администратора НЕ нужны (рекомендуется);
   - если нужен доступ для всех учётных записей ПК — щёлкните файл правой
     кнопкой и выберите «Запуск от имени администратора».
4. Дождитесь сообщения об успешной установке и нажмите любую клавишу.
5. Откройте AutoCAD обычным способом и запустите команду OPOR или XX.

APPLOAD не нужен. Плагин подхватывается самим AutoCAD: команды OPOR, XX,
OPORTIN, OPORGEOLEVELS, OPORSLOPELEVELS, OPORAUTOLEVEL, OPORCLEAN и OPORLOGS
работают сразу после установки.

ОБНОВЛЕНИЕ И СТАРЫЕ ВЕРСИИ

Установщик сам убирает предыдущие версии: все найденные OPOR.bundle в штатных
папках Autodesk переносятся в OPOR.bundle.backup-ДАТА-ВРЕМЯ, и остаётся ровно
одна живая копия. Ничего удалять вручную не нужно. Для обновления просто
выполните те же действия с новым архивом.

Важно: если AutoCAD был открыт во время установки, новая версия подхватится
только после его перезапуска.

ЧТО НОВОГО В 3.32

Кнопка «Гео» на панели и команда OPORGEOLEVELS — расстановка отметок по
геоподоснове со слоя GEO_POINTS. Порядок: кнопка Гео → указать замкнутый контур
→ выбрать режим (Сетка или Линии) → в режиме «Сетка» задать шаг. Значение шага
по умолчанию подставляется само: 1 м для метрового чертежа, 1000 мм для
миллиметрового.

Исходные точки геоподосновы не разрушаются: команда работает на временных копиях
и удаляет их за собой. Повторный запуск заменяет только прежние геоотметки,
поставленные вручную не трогает.

ВНИМАНИЕ: функция «Гео» новая и в живом AutoCAD ещё не обкатана. Если она себя
поведёт не так — соберите логи (см. ниже) и пришлите.

ЕСЛИ ПОЯВИЛАСЬ ОШИБКА

1. Закройте AutoCAD.
2. Запустите 2_СОБРАТЬ_ЛОГИ.cmd.
3. На рабочем столе появится ZIP вида OPOR_LOGS_ДАТА-ВРЕМЯ.zip.
4. Отправьте этот ZIP разработчику — внутри журналы установки, автозагрузки
   AutoCAD и работы команд OPOR.

Логи хранятся локально в %LOCALAPPDATA%\OPOR\logs.
Их также можно открыть из AutoCAD командой OPORLOGS.

ЗАПАСНОЙ ВАРИАНТ БЕЗ УСТАНОВКИ

Если установщик по какой-то причине не отработал, плагин можно подключить
вручную, без записи в системные папки: APPLOAD → «Группа автозагрузки» →
«Содержимое...» → «Добавить...» → выбрать файл
_OPOR_FILES\00_ЗАГРУЗИТЬ_OPOR.lsp, затем выделить его в верхнем списке APPLOAD и
нажать «Загрузить». Папку _OPOR_FILES в этом случае удалять нельзя.

Папка _OPOR_FILES содержит служебные файлы. Открывать или изменять её не нужно.
