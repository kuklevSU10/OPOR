# S4 «Плитка» — план реализации (v3.9-s4-tiles)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Порт режима «плитка» из VBA 1:1 (ковёр полилиний + резка Boolean-регионами + QC/QR в таблицу), без VBA-бага дублей у проёмов.

**Architecture:** Весь плиточный код — в `opor-tiles.lsp` (заглушка оживает), один вход `opor-tiles-run`, вызывается из Const/Var-ранов `opor-core.lsp` после `opor-grid-build` при `tile-mode="p"`. UI: покрытие становится выбираемым в Const (DCL-радио + командный вопрос), дв. лаги при плитке форсятся 0.

**Tech Stack:** AutoLISP + COM (`vla-AddRegion`, `vla-Boolean`: 0=Union/1=Intersection/2=Subtraction, `Explode` через `vlax-invoke` + `opor-variant-list`). Git нет: проверка = verify_opor.py + AutoCAD-прогоны, статус в HANDOFF.md.

**Спека:** `docs/superpowers/specs/2026-07-07-s4-tiles-design.md`. `opor.dcl` НЕ трогаем.
