# Протокол проверки плагина «opor» (golden master)

> Идея: зафиксировать поведение **оригинала** как эталон, затем прогнать те же сценарии
> на **переписанной** версии и сверить снимки состояния на идентичность.
> Инструмент замера — `check_dump.lsp` (команда `DUMPALL`).

---

# ЧАСТЬ 1. Что делает оригинальный плагин

## Запуск и меню

Команда запуска — **`xx`** (грузит `opor2.6.lsp`, тот запускает VBA-макросы из `oporav2.6.dvb`).
Появляется форма-меню (`ufrm_mode`) с **9 инструментами**:

| Кнопка | Режим (`arrfrm3`) | Что делает |
|--------|-------------------|------------|
| Опоры, постоянная высота | `c` | расстановка опор, одна высота на весь контур |
| Опоры, переменная высота | `v` | расстановка опор по блокам-отметкам + областям высот |
| Очистка | `clear` | удаляет служебные объекты/слои плагина |
| Уклон | `slope` | построение/расчёт уклона |
| Уклон с записью | `slopeWR` | то же + запись результата |
| Проверка высот | `check` | проверка отметок/высот |
| Авто-отметки | `auto_levl` | автоматическая расстановка блоков отметок |
| Запись отметки | `wr_levl` | ручная запись отметки |
| Кольцо | `ring` | инструмент «кольцо» |

Первые два → внутренний режим **`opor`** (главный, сложный). Остальные семь → режим **`other`**
(диспетчер `c_main`), каждый запускает свой одноимённый под-инструмент.

## Главный инструмент — расстановка опор (поток)

Для **каждого внешнего контура** (можно несколько за один запуск — цикл):

1. **Выбрать внешний контур** — замкнутая полилиния. Проверки: это полилиния, не
   самопересекающаяся; если не замкнута — предложит замкнуть.
2. *(перем. высота)* проверка: на всех ли вершинах есть блоки отметок `otmetka_oporvb`;
   есть ли области высот; чтение отметок (атрибут блока = высота).
3. **Указать начальную точку** (должна быть внутри контура).
4. **Задать направление** — двумя точками (угол линий сетки).
5. **Форма параметров** (`ufrm_steps`): шаг по вектору, шаг по перпендикуляру, отметка
   чистого пола, радиус опоры, толщины доска/лага/плитка, раскладка доска/плитка,
   лаги вдоль вектора/перпендикуляра, сдвоенные лаги (шаг), галка триангуляции.
6. *(пост. высота)* форма `ufrm_H`: выбрать наименование опоры + диапазон высот.
7. **Указать точку вставки итоговой таблицы** (один раз за запуск).
8. Плагин **строит**: сетку (XLines по шагам от нач.точки вдоль направления) →
   *(вариант плитка)* раскладку плиток с обрезкой → **обрезает сетку по контуру и
   проёмам** (сейчас это Express `extrim`) → ставит блоки опор → считает.
9. **Следующий контур** или Enter — завершить.
10. **Финал** (`fin`): заполняет итоговую таблицу, предупреждает об ошибках высот.

## Где плагин берёт данные (из чертежа/шаблона)

- **Таблица «Опоры»** (ACAD_TABLE, ячейка(0,0)="Опоры"): наименование | диапазон высот |
  номер цвета. Из неё определяется, какая опора по какому диапазону и каким цветом.
- **Блоки отметок** `otmetka_oporvb` — атрибут = высота (для переменной высоты).
- **Блоки-символы опор** (динамические): `opor_symb` (Level), `opor_symb3d` (3D),
  `opor_symbPRO` (PRO) — что ставится в точках.

## Что плагин создаёт (ВЫХОДЫ — это и проверяем)

- **Блоки опор** на слое `опорыvb`: символ по типу, масштаб = радиус/100, **цвет = диапазон
  высоты**, атрибут = высота. Ставятся в: вершинах контура + на границах (концы линий
  сетки) + в узлах сетки (пересечения вектор×перпендикуляр).
- **Сетка/лаги** на слое `сеткаvb`; **длина лаг** `gridleng` (в финале округляется до метров).
- **Плитка** (вариант «плитка»): целая `qplw` / обрезанная `qpltrim`.
- **Итоговая таблица**: количество опор по диапазонам, итого, длина лаг, площадь объекта.
- **Площадь**: сейчас по контуру; по ТЗ должно стать «контур − областиvb» (это правка, а не
  текущее поведение — при сверке учитывай).
- **Ошибки**: опоры цвета **30 (оранжевый)** = не определена высота (вне диапазонов таблицы);
  в финале выводится их количество.

## Модель данных (глобалы, для справки)

`arrfrm(1..11)` = шаг-вектор · шаг-перп · отметка пола · доска/плитка · радиус опоры ·
толщ.доски · толщ.лаги · толщ.плитки · вектор/перп · линейка(lev/3D/PRO) · сдвоенная лага.
`gridleng` — длина лаг · `qop` — всего опор · `arroporall` = |цвет|количество| · `areatotl` —
площадь · `qplw/qpltrim` — плитка целая/обрезанная.

# ЧАСТЬ 2. Трасса сверки

## Принцип

После прогона оригинала снимаешь снимок (`DUMPALL`) → потом тот же сценарий на переписанном →
снимки должны **совпасть**. Снимок объективный (числа), не «на глаз».

## Условие воспроизводимости (КРИТИЧНО)

Чтобы снимки были сравнимы, ввод должен быть **детерминированным**:

1. **Фиксированные исходные чертежи** — сохрани каждый сценарий отдельным `.dwg` (исходник
   ДО запуска плагина), чтобы переписанную версию гонять на точно таком же.
2. **Точки указывай координатами с клавиатуры, НЕ мышкой.** Иначе не повторишь. Например:
   нач. точка `0,0`; направление — `0,0` затем `1,0` (угол 0°); точка таблицы `5000,0`.
3. **Все числа формы записывай** (шаг, радиус, толщины и т.д.) — вводи одни и те же.
4. Один и тот же шаблон (`LEVEL 2025 V3.dwt`) — таблица «Опоры» и блоки одинаковые.

## Инструмент замера

`check_dump.lsp` → `APPLOAD`. После прогона плагина набираешь **`DUMPALL`** и копируешь вывод.
(Отдельные: `DUMPOPOR`, `DUMPLAG`, `DUMPAREA`, `DUMPLAYERS`, `DUMPTABLE`.)
Если контур у тебя не на слое «контур» — поправь `*contour-layer*` в начале файла.

## Сценарии (минимальный набор)

Для каждого: фиксированный чертёж + точный ввод + снимок `DUMPALL`.

| ID | Режим | Чертёж | Ключевой ввод |
|----|-------|--------|---------------|
| **S1** | Опоры, пост. высота, доска | прямоугольник | шаг 600/600, R=100, доска, вектор |
| **S2** | Опоры, перем. высота | контур + блоки отметок на вершинах | то же + триангуляция |
| **S3** | Опоры с проёмом | контур + полилиния-проём на `областиvb` | то же |
| **S4** | Опоры, вариант плитка | прямоугольник | раскладка «плитка», размер плитки |
| **S5** | Опоры 3D и PRO | прямоугольник | тип 3D, затем тип PRO |
| **S6** | Сдвоенные лаги | прямоугольник | задать шаг сдвоенной лаги |
| **S7** | Уклон (slope) | контур | по инструменту |
| **S8** | Проверка высот (check) | контур + отметки | по инструменту |
| **S9** | Авто-отметки (auto_levl) | контур | по инструменту |
| **S10** | Запись отметки (wr_levl) | — | по инструменту |
| **S11** | Очистка (clear) | результат S1 | — (должно всё убраться) |
| **S12** | Кольцо (ring) | — | по инструменту |

> Начни с **S1** (самый простой и детерминированный) — на нём отладишь и сам процесс сверки.
> S5 удобно гонять как часть тестов после правки диапазонов высот по ТЗ (235-340 и т.п.).

## Пример: детальная карточка сценария S1

**Исходный чертёж `S1.dwg`:** шаблон `LEVEL 2025 V3.dwt` + прямоугольный замкнутый контур
на слое «контур», углы `0,0` `5000,0` `5000,3000` `0,3000`.

**Точная последовательность ввода:**
```
Command: xx
[меню] -> Опоры, постоянная высота
Укажите внешний контур: (клик по полилинии ИЛИ ввести её выбор)
Укажите начальную точку: 0,0
Задайте направление: 0,0  затем  1,0
[форма ufrm_steps] шаг 600 / 600, радиус 100, доска, толщины по умолчанию, вектор -> OK
[форма ufrm_H] выбрать наименование (напр. первую строку) -> OK
Укажите точку таблицы: 7000,3000
Укажите следующий внешний контур: <Enter>  (завершить)
```
**Снимок:** `DUMPALL` -> скопировать весь вывод в колонку «Оригинал».

## Допуски при сверке

- **Целые** (кол-во опор, объектов на слоях, по цветам) — **точное** совпадение, без допуска.
- **Длина лаг / площадь** — допуск ~0.5 мм / 0.001 м² (плавающая точка). В идеале до мм.
- **Ячейки таблицы** — текстовое совпадение значений (числа в тех же ячейках).
- **Позиции блоков** — если понадобится строгая сверка координат, расширим `DUMPOPOR`
  (выгрузка точек вставки), но обычно совпадения количеств по цветам + длины лаг достаточно.

## Порядок работы

1. Подготовить чертежи S1..Sn (исходники до плагина), сохранить копии.
2. Загрузить `check_dump.lsp`.
3. **Оригинал:** на копии чертежа прогнать плагин по карточке сценария → `DUMPALL` →
   записать в «Оригинал».
4. *(позже)* **Переписанное:** на свежей копии того же чертежа — тот же сценарий → `DUMPALL` →
   записать в «Переписанное» → сверить.
5. Любое расхождение целых чисел = баг переноса, разбираем точечно.
