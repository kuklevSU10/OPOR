# OPOR v3.32.0 — установка и запуск

## Автоматическая установка — рекомендуемый способ

1. Полностью распакуйте ZIP в обычную папку.
2. Закройте все окна AutoCAD.
3. Установите OPOR файлом `1_УСТАНОВИТЬ_OPOR.cmd` в корне распакованной папки:
   - **обычный двойной клик** — установка для текущего пользователя Windows в
     `%APPDATA%\Autodesk\ApplicationPlugins`. Права администратора не нужны,
     запрос UAC не появляется. Это рекомендуемый способ;
   - **правый клик → «Запуск от имени администратора»** — установка для всех
     учётных записей ПК в `%PROGRAMDATA%\Autodesk\ApplicationPlugins`.
4. Дождитесь сообщения `OPOR installed ...` и нажмите любую клавишу.
5. Запустите AutoCAD обычным способом. Команды `OPOR` и `XX` уже должны быть
   доступны без `APPLOAD`.

## Диагностические логи

Установщик, автозагрузка AutoCAD и команды OPOR автоматически пишут журналы в
`%LOCALAPPDATA%\OPOR\logs`. Команда `OPORLOGS` открывает эту папку.

Если нужно отправить диагностику, закройте AutoCAD и запустите в корне выдачи
`2_СОБРАТЬ_ЛОГИ.cmd`. На рабочем столе появится готовый архив
`OPOR_LOGS_ДАТА-ВРЕМЯ.zip`.

Установщик помещает плагин только в архитектурно-нейтральные папки Autodesk
ApplicationPlugins (`%APPDATA%` или `%PROGRAMDATA%`), которые AutoCAD 2023
надёжно сканирует, — без неоднозначности `Program Files` / `Program Files (x86)`.
Для обновления запустите тот же файл ещё раз: прежние копии `OPOR.bundle` во
всех штатных корнях (в т.ч. ошибочный x86 из старых версий) переносятся в
резервные `OPOR.bundle.backup-ДАТА-ВРЕМЯ`, поэтому активной остаётся ровно одна.

Важно: установщик нельзя запускать прямо внутри ZIP — архив сначала необходимо
полностью распаковать.

## Важно

Не разносите папки `00_APPLOAD` и `OPOR`: они должны лежать рядом, как в
архиве. Плагин не требует старого VBA/DVB.

## Ручной запуск — запасной способ

1. Распакуйте всю папку `OPOR_v3.31.2_2026-07-23` в любое удобное место.
2. В AutoCAD выполните команду `APPLOAD`.
3. Загрузите `00_APPLOAD/01_OPOR_PORT.lsp`.
4. Запустите команду `OPOR` или `XX`.

Если при первом запуске появится окно выбора файла, укажите
`OPOR/opor-loader.lsp` внутри распакованной папки. Это нужно только для того,
чтобы загрузчик запомнил расположение модулей в текущем сеансе AutoCAD.

Если AutoCAD блокирует загрузку из новой папки, добавьте её в доверенные пути
AutoCAD (`TRUSTEDPATHS`) либо разрешите загрузку в стандартном предупреждении.

Если после автоматической установки команды отсутствуют, проверьте, что
системная переменная AutoCAD `APPAUTOLOAD` не равна `0`, и перезапустите AutoCAD.

## Что входит в версию 3.31

- расчёт Level 3D и Level PRO на постоянной и переменной высоте;
- TIN по отметкам, включая автоматические отметки вершин проёмов;
- доска, плитка на лагах и плитка напрямую на опорах;
- крепления TOP, CLIP, TILE и LASTRA с автоматическим суффиксом `3D`;
- учёт 4 мм на каждый выбранный вид крепления;
- автоматическая спецификация опор и таблица параметров по составу пола;
- очистка созданных объектов командой `OPORCLEAN`.

Основные подсказки по кнопкам доступны через кнопку `i` в главном окне OPOR.
