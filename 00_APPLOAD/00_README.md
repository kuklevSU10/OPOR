# Быстрая загрузка в AutoCAD

Открывайте в `APPLOAD` только эту папку. Файлы пронумерованы в обычном порядке работы:

1. `01_OPOR_PORT.lsp` — текущий чистый AutoLISP-порт. Команда `OPOR` или `XX`.
2. `02_VBA_ORIGINAL.lsp` — старый оригинальный OPOR для сравнения. Команда `XX`.
3. `03_TEST_TOOLS.lsp` — генераторы ETS1/2/3/7/8/9/10 и диагностика.

Для текущей проверки `h`:

1. Загрузить `03_TEST_TOOLS.lsp`, выполнить `ETS8`.
2. Загрузить `01_OPOR_PORT.lsp`, выполнить `OPOR` и нажать `?`.
3. После выполнения ввести `HEIGHTDUMP`.

Файлы проекта намеренно не перенесены: эта папка служит короткой и безопасной
«витриной», а загрузчики сами находят исходники относительно своего расположения.
