OPOR 3.35 — ручное подключение из архива

1. Полностью распакуйте архив в постоянную папку.
2. Не разносите содержимое: файл 00_ЗАГРУЗИТЬ_OPOR.lsp и папка OPOR
   должны оставаться рядом.
3. В AutoCAD выполните команду APPLOAD.
4. Откройте «Группа автозагрузки» → «Содержимое...» → «Добавить...».
5. Выберите 00_ЗАГРУЗИТЬ_OPOR.lsp из распакованной папки.
6. В основном окне APPLOAD выберите тот же файл и нажмите «Загрузить».
7. Запустите команду OPOR.

После добавления в «Группу автозагрузки» повторно подключать файл при каждом
старте AutoCAD не требуется.

Если AutoCAD один раз попросит указать файл плагина, выберите:
  OPOR\opor-loader.lsp
из этой же распакованной папки. Найденный путь запомнится.

Для разовой загрузки без автозапуска достаточно выполнить APPLOAD и загрузить
00_ЗАГРУЗИТЬ_OPOR.lsp, не добавляя его в «Группу автозагрузки».

Совместимость: Windows-версии AutoCAD 2023–2026 с поддержкой AutoLISP.
