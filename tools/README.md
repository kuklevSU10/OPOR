# Инструменты разработки OPOR

- `diagnostics/` — команды дампа и проверки результатов AutoCAD.
- `generators/` — генераторы эталонных DWG и сценариев ETS.
- `prototypes/` — ранние прототипы, сохранённые для истории решений.

Для обычной работы в AutoCAD открывайте папку `00_APPLOAD`. Файл
`03_TEST_TOOLS.lsp` загружает инструменты из этих подпапок автоматически.
