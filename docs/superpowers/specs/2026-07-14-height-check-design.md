# Инструмент `?` / `check_height` — дизайн порта (v3.11-height-check)

Дата: 2026-07-14. Статус: в реализации после принятого SLOPE.

## Назначение

Инструмент проверяет высоту одной уже установленной опоры в переменном плане.
Он не меняет расчётную сетку и исходные опоры, а строит в указанной пользователем
точке диагностическую выкладку:

- копию области `линии_высот`, содержащей опору;
- треугольник интерполяции, содержащий опору;
- красный блок `проверкаvb3` для выбранной опоры;
- три блока `проверкаvb3` для опор в вершинах треугольника.

## Семантика VBA

1. Выбрать внешний контур, затем блок опоры внутри области и точку вывода.
2. Допустимы только `opor_symb` и `opor_symb3d`; PRO исходный VBA отвергает.
3. Найти область на `линии_высот`, строго содержащую точку вставки опоры.
   Опора на границе не проверяется.
4. Прочитать блоки `otmetka_oporvb`, триангулировать только найденную область и
   выбрать первый треугольник, внутри или на границе которого лежит опора.
5. В каждой вершине треугольника найти опору того же типа с допуском
   `Abs(dx)<1`, `Abs(dy)<1`; первый атрибут — высота опоры.
6. Уровень пола VBA восстанавливает по первой вершине:
   `floor = triangle.az + vertex1_support_height`.
7. Диагностические атрибуты:
   - `LEV = floor - support_height`;
   - `H = "floor-support_height"`.
8. Масштаб центрального блока — `XScale выбранной опоры × 10`, вершинных — `×7`;
   центральный блок красный. Геометрия переносится вектором от выбранной опоры
   к точке вывода.
9. VBA через CAL `ILP` сравнивает `floor-selected_height` с Z плоскости
   треугольника; при расхождении больше 1 мм выдаёт предупреждение.

## Архитектура порта

Новый модуль `OPOR/opor-height-check.lsp` переиспользует:

- bbox/point-in-polygon и работу с COM из geometry;
- чтение отметок и триангуляцию из levels;
- атрибуты блоков из tables/supports;
- безопасную регистрацию XData и очистку из cleanup;
- save/restore view из dcl.

Проверка плоскости выполняется существующей barycentric-функцией
`opor-triangle-z-at-point`; это математический эквивалент CAL `ILP` без
асинхронного `SendCommand` и глобальной переменной USERS5.

Входы:

- кнопка `?` в DCL (проверено по реальной VBA-форме: `h` вызывает другой
  инструмент `write_levl`);
- keyword `Height` в командном fallback;
- прямая команда `OPORHEIGHTCHECK`.

Все шесть созданных объектов получают XData `OPOR` и чистятся `OPORCLEAN`.

## ETS8

Отдельный генератор создаёт прямоугольную область 3000×5000 с отметками
0/10/20/10, опорами в четырёх вершинах с высотами 100/90/80/90 и выбранной
внутренней опорой в точке (2000,1500) с высотой 90. Точка вывода — (7000,5000).

Ожидание для треугольника A(0,0,0)-B(3000,0,10)-C(3000,5000,20):

- восстановленный floor = 100;
- выбранная опора: LEV=10, H=`100-90`, цвет 1, scale=10;
- вершины: (LEV/H) = 0/`100-100`, 10/`100-90`, 20/`100-80`, scale=7;
- плоскость в (2000,1500) = 9.67 → округлённо 10, расхождение 0;
- создано: 4 блока проверки + копия области + треугольник.
